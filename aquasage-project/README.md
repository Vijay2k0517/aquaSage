# A Real-World Benchmark Dataset for Leakage Detection based on Repairs Records
A real-world benchmark dataset from a Cyprus water distribution network that pairs 5-minute DMA inlet flow time series with verified leakage repair logs (processed, severity-classified, and temporally aligned) to provide ground-truth labels for leakage detection and localization under operational conditions.

This dataset is released under the Creative Commons Attribution 4.0 International (CC BY 4.0) licence.
